# Look test

Run this on the PNG after the check report is clean. A no is a reason to change the spec.

1. **One question.** Can you say what this diagram answers in one sentence, and does the title say it?
2. **Entry point.** Does the eye land on the start of the main flow, at the top left or the start of the direction?
3. **Flow.** Does the main path read in one direction without doubling back?
4. **Grouping.** Do the boxes match how the reader thinks about the system (ownership, trust boundary, runtime)?
5. **Truth.** Does every part and wire exist in the sources? Is anything important missing?
6. **Words.** Are all labels one to three words? Is there any sentence on the canvas that belongs in `about`?
7. **Encoding.** Do solid, dashed and dotted wires mean what the spec says (sync, async, data)? Is tone used for at most one category?
8. **Size.** Is it readable at the width it will be seen? If not: change direction, split, or rely on the interactive page.
9. **Calm.** Is there anything you could remove without losing meaning? Remove it.
